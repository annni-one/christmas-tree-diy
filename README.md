# 圣诞树DIY · 点亮你的专属圣诞

纯前端实现的圣诞树装饰编辑器，支持自由搭配圣诞树、添加装饰、调整位置角度，一键生成专属圣诞贺卡。

---

## 功能一览

### 核心功能

| 模块 | 说明 |
|------|------|
| 🎄 圣诞树选择 | 11款不同风格的圣诞树可选（闪粉螺旋、星粒、线条、金粒、丝带、蓝粒、银白线、经典绿树、浅绿小树、带雪松果等） |
| 🎨 装饰素材库 | 6大类共30+款装饰素材：彩球、星星、闪光、铃铛、蝴蝶结、糖果 |
| ✋ 拖拽编辑 | 点击添加装饰，自由拖拽移动位置 |
| 🔍 缩放旋转 | 选中装饰后，右侧滑块调节大小和旋转角度 |
| 🎨 颜色切换 | 支持金色、红色、蓝色、粉色、绿色、白色6种颜色 |
| ✏️ 文字祝福 | 自定义主标题和副标题，实时预览 |

### 实用功能

- **撤销/重做**：最多50步历史记录，操作失误一键回退
- **清空画布**：一键清除所有装饰
- **自动保存**：操作后自动保存到本地，刷新页面自动恢复
- **导出图片**：生成2倍分辨率高清PNG，弹窗预览支持长按保存

## 使用方法

### 在线使用
直接打开 `index.html` 即可开始编辑。

### 小工具容器内使用
1. 将 `圣诞树DIY.zip` 上传至创服平台
2. 在平台模拟器中预览测试
3. 使用 Android / iOS 真机扫码验证

## 技术栈

- 纯 HTML / CSS / JavaScript，无任何框架依赖
- 所有素材均为透明背景PNG，已抠图处理
- 自适应布局，支持移动端和桌面端
- Canvas 2D 高清导出
